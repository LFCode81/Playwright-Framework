# Playwright .NET Test Automation Framework

## Overview
Production-style UI automation framework built using Playwright (.NET) to support scalable, maintainable end-to-end testing.

## Features
- Page Object Model (POM)
- Data-driven testing
- Parallel test execution
- CI/CD integration (GitHub Actions)
- Modular architecture (Pages, Components, Utilities)

## Tech Stack
- C#
- .NET
- Playwright
- MSTest
- GitHub Actions
